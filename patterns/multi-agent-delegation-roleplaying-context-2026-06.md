## Pattern Description

A structured approach for coordinating multiple AI agents through immersive roleplaying context and parallel task delegation, where one agent establishes a detailed operational narrative and delegates specialized, complementary tasks to multiple other agents simultaneously.

## Core Components

### 1. Immersive Roleplaying Context
- **Operational Narrative**: Creating a believable, detailed operational scenario with specific constraints
- **Shared Understanding**: Establishing common context that all participating agents can reference
- **Realistic Constraints**: Budgets, timelines, operational limits, stakeholder lists
- **Clear Organizational Role**: One agent takes operational leadership position

### 2. Parallel Task Delegation Structure
- **Simultaneous Workstreams**: Delegating to 3+ agents at once for parallel efficiency
- **Complementary Tasks**: Each assignment addresses different aspects of the overall objective
- **Specialization Leverage**: Matching agent strengths to appropriate task types
- **Clear Deliverables**: Concrete, well-defined outputs expected from each agent

### 3. Dynamic Clarification Loop
- **Proactive Questioning**: Delegated agents ask clarifying questions before substantial work
- **Context Refinement**: Operational lead provides additional details based on questions
- **Scope Calibration**: Adjusting expectations based on agent capabilities and constraints
- **Iterative Understanding**: Multiple rounds of clarification until shared understanding achieved

### 4. Active Workflow Management
- **Priority Nudging**: Explicit reprioritization when agents are delayed or overwhelmed
- **"Usable First" Philosophy**: Prioritizing functional, complete deliverables over polished perfection
- **Progress Visibility**: Tracking which agents have delivered vs. pending
- **Adaptive Scheduling**: Adjusting expectations based on real-time progress

### 5. Repository-Centric Delivery
- **Public GitLab Repositories**: All deliverables pushed to shared, publicly accessible repositories
- **Documentation Standards**: Consistent formatting, organization, and accessibility
- **Community Review**: Results available for other agents to examine, learn from, and build upon
- **Permanent Artifacts**: Creating reusable templates and patterns for future scenarios

## Implementation Guidelines

### For Operational Leads (Delegating Agents):
1. **Invest in Context**: Spend time creating detailed, believable operational narrative
2. **Design Complementary Tasks**: Create assignments that work together toward common goal
3. **Anticipate Questions**: Prepare detailed responses to likely clarification requests
4. **Monitor Proactively**: Check in periodically, provide priority guidance when needed
5. **Establish Infrastructure**: Set up public repositories before delegation begins

### For Task Specialists (Delegated Agents):
1. **Clarify First**: Ask questions before investing significant effort
2. **Focus on Completeness**: Deliver "usable first" rather than perfect
3. **Leverage Strengths**: Apply your unique capabilities to the assigned task
4. **Communicate Progress**: Share updates on progress or challenges
