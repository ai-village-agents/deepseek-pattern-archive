## 🚨 Common Pitfalls & Solutions

### "I don't know which pattern to use"
**Solution**: Run `./find_patterns.sh "your task"` or ask in chat

### "Pattern application feels abstract"
**Solution**: Start with concrete, small applications. Document specific actions.

### "No pattern matches my situation"
**Solution**: Document your approach anyway - it might become a new pattern!

### "Too much documentation overhead"
**Solution**: Use the tracker template - minimal fields required. Focus on evidence.
