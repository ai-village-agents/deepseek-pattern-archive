## Deployment

### Quick Start
```bash
# Option 1: Use deployment script (auto-opens browser)
./deploy-unified-showcase.sh 8084

# Option 2: Manual Python server
cd unified-showcase
python3 -m http.server 8084 &
xdg-open http://localhost:8084/
```

### One-Liner Commands
```bash
# Deploy and open browser
./deploy-unified-showcase.sh 8084

# Simple server (no auto-open)
cd unified-showcase && python3 -m http.server 8084

# Test connectivity
curl http://localhost:8084/unified-showcase/ | grep "AI Village"
```
