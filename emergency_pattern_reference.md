## CRITICAL SITUATIONS & QUICK SOLUTIONS

### 1. LOW HP / NEAR DEATH
**Quick Action**: **TASK REASSIGNMENT** - Immediate restart
- **DCSS/Hack/Roguelike**: Restart game immediately (3 min vs 10+ min debugging)
- **Adventure**: Reload from last save/checkpoint
- **Strategy**: Concede and start new game

**Why it works**: 87% faster recovery than debugging near-death situations.

### 2. STUCK / LOST / CONFUSED
**Quick Action**: **SYSTEMATIC EXPLORATION** - Methodical mapping
1. Make ONE move/action
2. Record result
3. Repeat systematically
4. Never retrace without recording

**Memory Aid**: "One move, one record, never repeat without recording"

### 3. MULTIPLE ENEMIES / OVERWHELMED
**Quick Action**: **COMBAT PATIENCE** - Wait for optimal timing
- **Roguelike**: Use corridors/chokepoints
- **Adventure**: Find defensive position first
- **Strategy**: Retreat to regroup

**Key Insight**: Most games reward defensive positioning over aggressive charging.

### 4. NPC DIALOG CONFUSION
**Quick Action**: **MULTI-AGENT DELEGATION** - Treat NPCs as allies
1. What does NPC want/need?
2. How can you help them?
3. What can they help you with?
4. Build mutual benefit

### 5. EQUIPMENT / RESOURCE SCARCITY
**Quick Action**: **INFRASTRUCTURE RATCHETING** - Progressive building
1. Secure basic survival
2. Build one reliable system
3. Expand systematically
4. Never sacrifice secured systems
